high Confirmed Anthropic Research · Nov 15, 19:00

Anthropic shortens its vulnerability disclosure deadline from 90 to 30 days for serious bugs

For reports made from January 1, 2027, Anthropic will disclose high and critical issues after 30 days instead of 90, and other issues after 45. It will escalate to an outside coordinator after 15 days of maintainer silence instead of 30, and publish full technical details 30 days after a patch instead of 45. The seven-day window for actively exploited bugs is unchanged, and hard-to-deploy software can get a vendor-agreed timeline.

Why it matters to you

Anthropic argues the 90-day norm assumed fixes moved at human speed and that rediscovery was unlikely, and that frontier models have broken both assumptions. If other researchers follow, vendor patch SLAs built around 90 days will be too slow.

Action

Check whether your product's vulnerability response SLAs can meet a 30-day disclosure window for high and critical issues.

medium Confirmed Hugging Face Blog · Nov 15, 19:00

Hugging Face routes language-model inference through OpenRouter across 80+ providers

Hugging Face Inference Providers now sends language-model requests through OpenRouter's router, which picks a provider per call on live price, speed and reliability and retries elsewhere on failure. It supports the OpenAI Chat Completions and Responses APIs and the Anthropic Messages API, with model-id suffixes such as :fastest, :cheapest or a named provider. Users pay provider prices on their Hugging Face bill with no markup; custom provider keys no longer work for language models.

What changed
One HF token reaches open-weight models across 80+ hosting providers with automatic failover.
Opportunity
Easier multi-provider access to open-weight models without managing separate accounts.

Why it matters to you

Dynamic routing means the company processing your prompts can change per request. For data-handling commitments, pin a provider or disable unapproved ones in organization settings.

Action

If your teams use HF Inference Providers, review org provider settings so requests only go to approved processors.

AI & Agentic Security2

high Likely Google Threat Intelligence (Mandiant) · Nov 16, 09:00

GTIG: attackers fully automate vulnerability discovery and exploitation with agentic frameworks

Google Threat Intelligence Group and Mandiant report that threat actors have moved from basic prompting to autonomous multi-agent frameworks, and for the first time observed LLM frameworks automating vulnerability discovery and exploitation with no human in the loop. Examples include an exposed staging server running an exploit agent that diffed patches, drafted exploits and ran them, and open-source offensive frameworks such as ARTEX, CAIRN and PentAGI seen in the wild. Mandiant also saw LLMJacking incidents with fraudulent model charges above $100,000 in a single day.

Why it matters to you

Patch-diff-to-exploit automation shrinks the gap between a fix shipping and attacks starting. GTIG also notes LLMs produce many claimed exploits that don't work, which adds verification load for defenders.

Action

Treat newly patched internet-facing bugs as exploited within days, protect and monitor LLM API keys like cloud credentials, and watch for anomalous model spend.

  • LLMJacking detection and key hygiene

high Confirmed AWS Security Bulletins · Nov 16, 16:03

AWS Labs MCP servers: token exfiltration and arbitrary file write via agent-controlled parameters

CVE-2026-126681 in the Timestream for InfluxDB MCP Server (0.0.12 to before 0.0.19) lets a remote, unauthenticated attacker use prompt injection to send the server's configured InfluxDB API token to an endpoint they control, via an InfluxDB URL introduced into the MCP client context. CVE-2026-126816 in the AWS Pricing MCP Server (before 1.0.31) lets anyone who can influence the agent write attacker-controlled content anywhere on disk through absolute paths or traversal in the report output path.

Why it matters to you

Both bugs treat tool arguments as trusted, but in an agent those arguments can come from injected content. The token leak is the clearer lesson: a server that holds a credential and accepts a destination from the model will send that credential wherever the model is told.

Action

Upgrade both servers. In MCP servers you build or review, pin outbound endpoints in configuration rather than accepting them as tool arguments, and confine file writes to a fixed directory.

  • Path canonicalization and directory confinement
