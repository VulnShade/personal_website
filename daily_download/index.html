Google launches Gemini Decision 1, a 'decision model' for single-pass classification

Gemini Decision 1 scores closed-set choices (yes/no, up to 255 options, or rubric scores) in a single pass instead of generating tokens, with multimodal input, a 256K context, up to 1,000 questions per request and a confidence score per answer. At the AI Engineer summit, Cloudflare described a hybrid agent in which fast decision models handle tool selection and log extraction while a large model only does diagnosis.

What changed
Cheap, calibrated, low-latency classification becomes a first-class API, separate from generative models.
Evidence
Vendor + independentGoogle reports 92.2% vs 90.0% for Jev 1.14 on JevBench and wins on 5 of 7 shared benchmarks. Artificial Analysis scores it 66 on its Decision Index, tied with Jev 1.14, at about 211 ms per task. Cloudflare says its demo went from six LLM calls to one and about 40K tokens to 1.8K.
Opportunity
Routing, guardrail checks, triage and tool selection in agent pipelines can move to a cheaper, faster model with calibrated confidence.

Why it matters to you

Security classifiers in agent pipelines (injection detection, policy checks, triage) are a natural fit, and a calibrated confidence score supports thresholds and human review.

  • Hybrid agent architectures with router models

AWS mcp-gateway-registry: SSRF to instance metadata and self-assignable registry admin

AWS disclosed two flaws in its open-source mcp-gateway-registry. CVE-2026-125926 is an SSRF in the server registration and update API that lets an authenticated user reach internal services and cloud instance metadata and read the responses (fixed in 1.35.0). CVE-2026-100307 is missing authorization on the external management API, letting an authenticated user assign the registry administrator scope to their own group via a crafted group import (versions 1.0.9 to 1.24.7).

Why it matters to you

MCP gateways centralize tool access for many agents, so a registry admin controls every registered tool. Registering a server means fetching a user-supplied URL, which is the textbook SSRF shape; any MCP registry or gateway you build or adopt needs egress controls and strict authorization on its management plane.

Action

If you run mcp-gateway-registry, upgrade to 1.35.0 or later, require IMDSv2 on its hosts, and audit group imports and admin scope assignments.

Learn
  • SSRF defenses for URL-fetching registration flows
  • Authorization on management and import APIs

high Confirmed BleepingComputer · Nov 11, 10:12

Attackers run the AntiFox agentic pentest platform to steal AWS credentials

Arctic Wolf observed several intrusions in which attackers hosted AntiFox, an open-source agentic penetration testing platform, on Alibaba Cloud. The agents exploited vulnerabilities, deployed an ASPX webshell on an exposed IIS server, harvested connection strings and configuration, then used valid IAM user credentials and assumed EC2 roles against AWS APIs. In one intrusion the attacker cycled identities through hundreds of API calls in about 30 minutes; most were denied, but some obtained production secrets.

Why it matters to you

Agentic offensive tooling is now in criminal use and changes the tempo of cloud intrusions: many fast, mostly failing attempts in which a few successes matter. Usage restrictions in an open-source project do nothing to stop this.

Action

Alert on successful API calls inside bursts of AccessDenied errors, correlate webshell activity with unusual AWS access, keep long-term keys out of application config, and require IMDSv2.

  • CloudTrail detection for denial-burst patterns
  • Workload identity instead of long-term IAM keys

medium Confirmed Wiz Blog & Research · Nov 11, 14:49

Apache httpd mod_http2 race condition enables claimed unauthenticated RCE (CVE-2026-119618)

A race condition in mod_http2's header handling causes heap corruption, which Wiz says may allow unauthenticated remote code execution. It affects httpd 2.4.55 through 2.4.70 with HTTP/2 enabled and is fixed in 2.4.71. The bug is credited to Anthropic and Google Cloud's vulnerability research team; no exploit or in-the-wild exploitation is reported.

Why it matters to you

Included for its reach and its source: concurrency bugs in core protocol handlers are hard to find, and this one came from AI-focused vulnerability research teams. Wiz's 64% exposure figure ignores configuration, so the real exposure is lower.

Action

Upgrade to httpd 2.4.71, or set Protocols http/1.1 until you can.

medium Confirmed PortSwigger Research · Nov 11, 09:26

PortSwigger: stealing credentials from HTML injection despite a strict CSP

Gareth Heyes shows two ways around CSP after an HTML injection. Allow-listed hosts that serve JSONP endpoints or old AngularJS give script gadgets. Even with default-src 'none', an injected self-posting form can reflect a second payload that sets an unsafe-url referrer policy and a meta refresh, leaking the full URL, credentials included, to an attacker's server, because form-action does not inherit from default-src.

Why it matters to you

CSP is often treated as a backstop for injection bugs. Host allow-lists and an unset form-action leave real gaps, so a policy review needs to look at gadgets on allowed hosts, not only at the directives.

Action

Prefer nonce- or hash-based CSP with strict-dynamic, set form-action explicitly, and keep credentials out of URLs.

  • Script gadgets on allow-listed hosts

high Confirmed BleepingComputer · Nov 11, 15:54

Fireworks AI breach exposed Notion AI chat transcripts from an analytics dataset

Fireworks AI, which runs some open-weight models for Notion AI and analyzed stored conversations for Notion's admin Insights feature, confirmed attackers accessed customer data, including Notion users'. Fireworks says an attacker reached its development environment through a third-party cloud provider on October 23, after an earlier October breach exposed API keys and tokens stored as environment-variable secrets. Notion says fewer than 1% of users are affected, cut traffic to Fireworks by November 3, and has disabled the Insights dataset.

Why it matters to you

The exposure came from a secondary use (analytics on stored conversations), not inference itself. AI subprocessors accumulate prompt data that users treat as private, and each extra use of that data widens the blast radius.

Action

Inventory which AI providers retain prompts or transcripts and for what purpose; require zero retention for inference and review any analytics or training pipelines that copy conversations. Advise users to rotate credentials pasted into chats.

Learn
  • AI vendor data-flow mapping and zero-retention contracts
  • Secrets in environment variables vs. a secrets manager

high update Confirmed BleepingComputer · Nov 11, 16:27

eMudhra revokes 8 more intermediate CAs; 16 affected after HSM key-migration failures

Updatenew developments in an ongoing story

A custom Python script used in April 2025 to move CA keys between HSMs from different vendors reduced eight ECDSA private keys to a single byte, which a researcher recovered by trying 256 values. eMudhra has now also revoked eight RSA intermediates whose keys were processed in host memory rather than inside an HSM, because it could not show compliance with its CPS. Browser and OS vendors have shipped protections that block the compromised certificates.

Why it matters to you

This is a trust failure in the web PKI caused by operational tooling, not cryptography. It shows why key ceremonies need independent verification of key strength and why custom scripts that handle key material are a critical risk.

Action

Check whether any of your services or pinned trust stores chain to eMudhra intermediates, and review your own HSM migration and key-generation procedures for post-migration key validation.

Learn
  • CA/Browser Forum key-protection requirements
  • HSM key migration and key ceremony controls
